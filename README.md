Project Tartan Tech Canada System: Hybrid Debian-GNOME Build System
Welcome to the repository for Debian with Canonical PPA support, a specialized build system designed to generate a modern, high-performance Linux operating system based on a pure Debian GNU/Linux core, exclusively integrated with Canonical’s advanced user-space management tools.

This project provides a fully automated debootstrap script that constructs a stable, unbloated Debian system (targeting stable, testing, or sid) while layering in critical Ubuntu/Canonical infrastructure. This approach delivers the robustness of Debian with the convenience of Ubuntu's driver management, firmware updates, and PPA support, all presented within a clean, strict GNOME desktop environment.🐧 FeaturesPure Debian Core: Built directly from official Debian repositories, ensuring long-term stability, security, and predictability.Dynamic Branch Targeting: Easily switch between Debian stable, testing, or unstable (sid) via a single build argument.Strict GNOME Desktop: Deploys a clean, unadulterated GNOME Shell and GDM3 environment. No unwanted window managers, alternative desktop environments, or bloatware are included by default.Canonical Driver Management (ubuntu-drivers):

Includes Canonical's proprietary hardware detection tools, allowing easy installation of NVIDIA, AMD, and specialized Wi-Fi drivers on Debian.Unified Firmware Management (fwupd & firmware-updater): Integrates the system-level fwupd daemon with Canonical’s dedicated Firmware Updater GUI for safe UEFI, peripheral, and component updates.PPA Support: Equipped with software-properties-gtk (Software & Updates) and add-apt-repository, enabling secure integration with Launchpad Personal Package Archives.GNOME Software Store: A fully functional GUI storefront configured to handle Debian packages, Flatpaks, and firmware.Future-Proof Canonical Layer: Includes an automated utility (upgrade-ubuntu-layer) that dynamically detects and transitions your Ubuntu component layer to the newest stable release (LTS or interim) as they are launched by Canonical.
