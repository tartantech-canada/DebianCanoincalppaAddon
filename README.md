Project Tartan Tech canada System: Hybrid Debian-GNOME Build SystemWelcome to the repository for Project Tartan, a specialized build system designed to generate a modern, high-performance Linux operating system based on a pure Debian GNU/Linux core, exclusively integrated with Canonical’s advanced user-space management tools.This project provides a fully automated debootstrap script that constructs a stable, unbloated Debian system (targeting stable, testing, or sid) while layering in critical Ubuntu/Canonical infrastructure. This approach delivers the robustness of Debian with the convenience of Ubuntu's driver management, firmware updates, and PPA support, all presented within a clean, strict GNOME desktop environment.🐧 FeaturesPure Debian Core: Built directly from official Debian repositories, ensuring long-term stability, security, and predictability.Dynamic Branch Targeting: Easily switch between Debian stable, testing, or unstable (sid) via a single build argument.Strict GNOME Desktop: Deploys a clean, unadulterated GNOME Shell and GDM3 environment. No unwanted window managers, alternative desktop environments, or bloatware are included by default.Canonical Driver Management (ubuntu-drivers):

Includes Canonical's proprietary hardware detection tools, allowing easy installation of NVIDIA, AMD, and specialized Wi-Fi drivers on Debian.Unified Firmware Management (fwupd & firmware-updater): Integrates the system-level fwupd daemon with Canonical’s dedicated Firmware Updater GUI for safe UEFI, peripheral, and component updates.PPA Support: Equipped with software-properties-gtk (Software & Updates) and add-apt-repository, enabling secure integration with Launchpad Personal Package Archives.GNOME Software Store: A fully functional GUI storefront configured to handle Debian packages, Flatpaks, and firmware.Future-Proof Canonical Layer: Includes an automated utility (upgrade-ubuntu-layer) that dynamically detects and transitions your Ubuntu component layer to the newest stable release (LTS or interim) as they are launched by Canonical.

Install Host PrerequisitesYour host system requires bootstrapping tools. Open a terminal and run:Bashsudo apt update

sudo apt install -y debootstrap squashfs-tools genisoimage curl systemd-container
2. Download the Build Script
Download the latest unified build script in this repo to your machine.
3. Make the Script Executable Bash example: chmod +x build-os.sh
4. Execute the BuildRun the script with root privileges. By default, the script targets Debian stable (rolling automatically to future stable releases).To build the default version:Bashsudo ./build-os.sh
To build a different Debian branch (e.g., testing):Bashsudo ./build-os.sh testing
(The build process typically takes 3 to 15 minutes, depending heavily on your internet connection speed.) Output and DeploymentOnce the script completes successfully, your custom operating system root filesystem is fully assembled and located at:Plaintext/opt/custom-debian-os

To turn this directory into a bootable installation medium, you must package it into an ISO image. You can use tools like xorriso or mkisofs to create a bootable ISO (e.g., by adding a standard Debian or Ubuntu live-boot kernel/initramfs and bootloader configuration).🛡️ Advanced: Hybrid APT PinningBecause this system mixes Debian core packages with Ubuntu user-space tools, APT pinning is critical.The build script automatically configures /etc/apt/preferences.d/hybrid-pinning inside the chroot. This configuration enforces that Debian core packages always take precedence (Priority 900) over foreign Ubuntu packages (Priority 100), preventing system library corruption during branch upgrades.To manually upgrade your system once booted:Bashsudo apt update
sudo apt dist-upgrade
Updating the Canonical LayerTo ensure your drivers, firmware tools, and PPA management utilities stay aligned with the newest upstream releases from Canonical, run the included utility inside your Debian Canonical hybrid OS installation
sudo upgrade-ubuntu-layer
